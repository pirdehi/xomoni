## خلاصه‌ی مدیریتی

Xomoni یک **افزونه‌ی Chrome** و یک **سایت همراه (xomoni.com)** است. با آن صاحب یک حساب X پست‌ها، ریپلای‌ها، ریپست‌ها و لایک‌های قدیمی‌اش را با قاعده‌های دقیق پاک می‌کند، یک نسخه‌ی کامل از حسابش نگه می‌دارد، و همه‌ی این‌ها را با سرعتی انجام می‌دهد که حساب در خطر نیفتد.

| شاخص | مقدار |
| --- | --- |
| نسخه‌ی منتشرشده | **0.2.0** روی [GitHub Releases](https://github.com/pirdehi/xomoni/releases) |
| کارهای نقشه‌ی راه | **۹۲ از ۹۷** انجام شده |
| فازهای تمام‌شده | **۸ از ۱۳** (فاز ۰ تا ۱۲) |
| Pull requestهای مرج‌شده | **۱۰۴** |
| Issueهای بسته‌شده | **۹۷** |
| تصمیم‌های معماری ثبت‌شده (ADR) | **۲۲** |
| تست‌های خودکار | **۱٬۲۴۶** تست افزونه و **۵۶۷** تست سایت، به‌علاوه‌ی تست‌های پایگاه داده و end-to-end |
| آزمایش واقعی (پایلوت) | همه‌ی پست‌های قبل از ۲۰۱۹ حساب مالک پروژه پاک شد و حساب سالم ماند |

**سه اصل که در همه‌ی محصول رعایت شده:**
- **داده‌های X از کامپیوتر شما بیرون نمی‌رود.** پست‌ها، لایک‌ها و آرشیو فقط در مرورگر خودتان می‌مانند ([ADR-0004](../../adr/0004-x-data-stays-local.md)).
- **بدون رمز، بدون دور زدن X.** Xomoni رمز X را نمی‌خواهد و نگه نمی‌دارد، درخواست جعل نمی‌کند، کپچا حل نمی‌کند و خودکار بودنش را پنهان نمی‌کند ([ADR-0003](../../adr/0003-no-credentials-no-evasion.md)).
- **یک‌پنجم هر محدودیت.** Xomoni هیچ‌وقت بیشتر از یک‌پنجم محدودیتی که X اعلام می‌کند مصرف نمی‌کند ([ADR-0012](../../adr/0012-one-fifth-of-every-x-limit.md)).

## Xomoni چیست و چه مشکلی را حل می‌کند

پاک کردن سال‌ها پست در X سخت‌تر از آن است که باید باشد:

| راه موجود | مشکلش |
| --- | --- |
| **API رسمی X** | پولی است و برای حذف کند: حداکثر ۵۰ حذف در هر ۱۵ دقیقه. |
| **اسکریپت‌هایی که مستقیم به API داخلی X درخواست می‌فرستند** | X حالا روی بیشتر درخواست‌ها یک هدر ضدربات امضاشده می‌خواهد؛ این ابزارها مدام از کار می‌افتند. |
| **اسکریپت‌های کپی‌وپیست در کنسول** | محدودیت‌های X را نادیده می‌گیرند، بعد از هشدار X هم ادامه می‌دهند و حساب را در معرض قفل شدن می‌گذارند. |

**راه Xomoni:** داخل همان تب X که با آن وارد شده‌اید کار می‌کند و همان دکمه‌هایی را می‌زند که شما می‌زنید. هر درخواست را خود X با همه‌ی هدرهایش می‌فرستد. Xomoni فقط پاسخ X را **می‌خواند** تا مطمئن شود هر کار انجام شده، و هدرهای محدودیت X را زیر نظر داشته باشد.

**برای چه کسی است:** هر کسی که می‌خواهد گذشته‌ی حساب X خودش را مرتب کند: پست‌های قدیمی را پاک کند، یک نسخه‌ی کامل نگه دارد، و این کار را بدون نوشتن کد و بدون به خطر انداختن حسابش انجام دهد.

## ساختار محصول در یک نگاه

| بخش | کجا اجرا می‌شود | چه کاری می‌کند | چه داده‌ای دارد |
| --- | --- | --- | --- |
| **داشبورد افزونه** | صفحه‌ای از افزونه در Chrome | موتور کارها، محدودکننده‌ی سرعت، قاعده‌ها و همه‌ی صفحه‌ها | همه‌چیز، فقط در IndexedDB مرورگر شما |
| **اسکریپت محتوا** | داخل پنجره‌ی X | دکمه‌های X را می‌زند و پاسخ‌های X را فقط می‌خواند | هیچ‌چیز نگه نمی‌دارد |
| **Service worker** | پس‌زمینه‌ی افزونه | پست‌هایی را که X نشان می‌دهد در «نسخه‌ی شما» ثبت می‌کند و آرشیو X را در پوشه‌ی درست ذخیره می‌کند | IndexedDB مرورگر |
| **xomoni.com** | Vercel، با پایگاه داده‌ی Supabase | حساب کاربری، اتصال مرورگر، دیدن وضعیت کارها از هر دستگاه | فقط وضعیت کارها: عنوان، حالت و شمارش‌ها؛ هیچ محتوایی از X |

سایت **فقط نمایش می‌دهد**. هیچ کاری را روی X شروع، ادامه یا تأیید نمی‌کند ([ADR-0006](../../adr/0006-website-is-view-only.md)).

## قابلیت‌ها

### ۱. پاک‌سازی حساب (Cleanup)

| قابلیت | چه کاری انجام می‌دهد |
| --- | --- |
| **پاک‌سازی بر اساس تاریخ** | پست، ریپلای، ریپست یا لایک‌های قدیمی‌تر از یک تاریخ یا بین دو تاریخ را حذف می‌کند. |
| **سه سؤال ساده** | چه چیزی، چقدر قدیمی، و مرور نهایی با دکمه‌ی *Start*. |
| **قاعده‌های نگه‌داشتن** | پست‌هایی با حداقل N لایک، پست‌هایی با کلمه‌های خاص، لینک‌هایی که خودتان می‌دهید، و ریپلای‌های داخل رشته‌های خودتان می‌مانند. |
| **پیش‌نمایش قبل از اجرا** | دقیقاً نشان می‌دهد چه چیزی پاک می‌شود و چقدر طول می‌کشد. یک نسخه‌ی پشتیبان JSON می‌دهد و تأیید با تایپ `DELETE` می‌خواهد. |
| **فراتر از سقف ۳٬۲۰۰ پست پروفایل** | جست‌وجوی X را صفحه‌به‌صفحه می‌گردد و آرشیو رسمی X را هم وارد می‌کند، پس پست‌های خیلی قدیمی هم پیدا می‌شوند. |
| **پاک‌سازی عمیق** | چیزی که فقط در آرشیو هست، یکی‌یکی باز می‌شود و قبل از حذف دوباره با قاعده سنجیده می‌شود. |
| **فقط پست‌های خودتان** | قبل از حذف بررسی می‌کند که پست مال حساب خودتان است. پست دیگران هیچ‌وقت لمس نمی‌شود. |
| **تأیید از پاسخ X** | یک پست فقط وقتی «حذف‌شده» حساب می‌شود که پاسخ خود X آن را تأیید کند. هر چیزی که قابل تأیید نباشد دست‌نخورده می‌ماند. |
| **کارهای قابل ادامه** | کار را متوقف کنید، مرورگر را ببندید و بعداً از همان‌جا ادامه دهید. |

### ۲. ایمنی حساب

| قابلیت | چه کاری انجام می‌دهد |
| --- | --- |
| **قاعده‌ی یک‌پنجم** | حداکثر ۱۰ حذف در هر ۱۵ دقیقه (X ۵۰ اعلام کرده)، ۴۰ در ساعت؛ آنلایک حداکثر ۲۰۰ در روز. تنظیم دستی می‌تواند کندتر باشد، هیچ‌وقت تندتر نه. |
| **گرم شدن تدریجی** | حساب تازه روز اول با یک‌چهارم این سرعت شروع می‌کند و از روز چهارم به سرعت کامل می‌رسد. |
| **جلسه‌های کار با استراحت** | تأخیرهای متغیر، استراحت ۱۰ تا ۳۰ دقیقه بعد از هر ۲۵ تا ۵۰ دقیقه کار، و ساعت‌های فعال (پیش‌فرض ۸ تا ۲۳). |
| **نردبان ریسک** | با هر نشانه‌ی هشدار از X، یک پله زودتر از خود X سرعت را کم می‌کند. |
| **توقف در اولین هشدار** | با کد ۲۲۶ («به نظر خودکار است»)، تعلیق، محدودیت یا رد شدن نوشتن، کار فوراً متوقف می‌شود. |
| **آزمایش قناری** | قبل از اولین حذف هر کار، یک حذف آزمایشی بررسی می‌شود. |
| **بررسی نمونه‌ای** | نمونه‌ای از حذف‌ها بعداً دوباره روی X بررسی می‌شود تا مسدود شدن بی‌صدا معلوم شود. |
| **گزارش سلامت حساب** | بعد از هر کار، سطح ریسک و دلیلش به زبان ساده نشان داده می‌شود. |
| **رضایت آگاهانه** | قبل از اولین کار برای هر حساب، متن ریسک‌ها نشان داده می‌شود و تایپ `I UNDERSTAND` لازم است. |
| **دست دادن به شما** | وقتی X ورود، کد دومرحله‌ای، کپچا یا باز کردن قفل حساب می‌خواهد، کار صبر می‌کند، اعلان می‌دهد، و بعد از اینکه شما کار را روی X انجام دادید، خودش ادامه می‌دهد. |

### ۳. نسخه‌ی شما و آرشیو X (Library)

| قابلیت | چه کاری انجام می‌دهد |
| --- | --- |
| **«نسخه‌ی شما» در یک کارت** | نشان می‌دهد Xomoni چند درصد از شمارش خود X را دارد و هر منبع آخرین بار کی خوانده شده. |
| **Get my archive** | آرشیو رسمی X را برایتان درخواست می‌کند، صبر می‌کند تا X بسازدش (۱ تا ۳ روز)، خودش سر می‌زند، دانلودش می‌کند و وارد می‌کند. رمز را فقط خودتان روی صفحه‌ی X وارد می‌کنید. |
| **ورود خودکار از Downloads › Xomoni** | آرشیو X در پوشه‌ی Xomoni ذخیره می‌شود و بدون هیچ کاری وارد می‌شود. |
| **ورود فایل ZIP همان‌طور که X می‌فرستد** | بدون باز کردن فایل؛ فقط سه فایل لازم خوانده می‌شود و عکس‌ها، ویدیوها و پیام‌ها هیچ‌وقت. |
| **خواندن از X** | پروفایل، ریپلای‌ها، لایک‌ها و کل تاریخچه را از جست‌وجوی X می‌خواند، با همان سرعت محتاط، بدون هیچ تغییری روی X. |
| **دانلود یک نسخه** | هر بازه‌ی تاریخی را به‌صورت صفحه‌ی HTML یا JSON روی کامپیوترتان ذخیره می‌کند. |
| **مرور و جست‌وجو** | همه‌ی پست‌های نسخه‌ی شما قابل جست‌وجو و فیلتر است. |

| قابلیت | چه کاری انجام می‌دهد |

### ۸. امنیت و حریم خصوصی

- **افزونه:** دسترسی شبکه فقط به API خود Xomoni، بدون دسترسی به سایت‌ها، بدون اجرا در حالت ناشناس، فقط پیام‌های خودش را باور می‌کند.
- **سایت:** Trusted Types، گزارش نقض CSP، هدرهای امنیتی، بررسی Origin.
- **پایگاه داده:** Row Level Security روی همه‌ی جدول‌ها، هیچ جدولی خودبه‌خود باز نیست، فقط اتصال رمزشده، کانال‌های Realtime خصوصی، و توکن مرورگر بعد از ۹۰ روز بی‌استفاده باطل می‌شود.
- **انتشار:** ساخت با توکن فقط‌خواندنی، امضای منشأ ساخت (SLSA)، فایل ZIP قابل بازسازی، و checksum.
- **پایش:** CodeQL روی هر تغییر، و `security.txt` برای گزارش آسیب‌پذیری.

### ۹. کیفیت مهندسی

- TypeScript با سخت‌گیرانه‌ترین تنظیم‌ها و lint آگاه از نوع ([ADR-0016](../../adr/0016-strict-typescript-and-type-aware-lint.md)).
- برای هر قابلیت، تست هر دو طرف، با حالت‌های خطا و امنیتی ([ADR-0017](../../adr/0017-test-standard.md)).
- قاعده‌های لایه‌بندی معماری که در CI بررسی می‌شوند ([ADR-0015](../../adr/0015-architecture-styles-principles-and-patterns.md)).
- هیچ تغییری بدون گذشتن از `verify`، تست پایگاه داده و end-to-end مرج نمی‌شود.

## با Xomoni چه کارهایی می‌توان کرد

| سناریو | چطور |
| --- | --- |
| **پاک کردن همه‌ی پست‌های قبل از یک سال، با نگه‌داشتن پست‌های محبوب** | Cleanup ← پست‌ها و ریپلای‌ها ← قدیمی‌تر از تاریخ ← استثنا: «۵۰ لایک یا بیشتر» ← Start |
| **برداشتن همه‌ی لایک‌های قدیمی** | Cleanup ← لایک‌ها ← بازه‌ی تاریخ |
| **نگه‌داشتن یک نسخه‌ی کامل از حساب قبل از پاک‌سازی** | Library ← *Get my archive*؛ Xomoni بقیه را خودش انجام می‌دهد |
| **دانلود پست‌های یک سال خاص به‌صورت صفحه‌ی قابل‌خواندن** | Library ← *Download a copy* ← انتخاب تاریخ‌ها ← HTML |
| **پیگیری یک هشتگ یا عبارت** | Watch ← افزودن تب |
| **دیدن وضعیت پاک‌سازی از موبایل** | اتصال افزونه به xomoni.com با کد یک‌بارمصرف ← داشبورد سایت |
| **ارائه‌ی گزارش از کارهای انجام‌شده** | Activity ← Log ← خروجی CSV یا JSON، با لینک هر پست |

## آنچه Xomoni عمداً انجام نمی‌دهد

Xomoni ابزار **مرتب کردن حساب خودتان** است، نه ابزار مدیریت شبکه‌های اجتماعی. این موارد عمداً در آن نیست:

- **انتشار یا زمان‌بندی پست، لایک یا ریپلای خودکار:** با قوانین X در تضاد است ([ADR-0003](../../adr/0003-no-credentials-no-evasion.md)). Watch فقط می‌خواند.
- **مدیریت دنبال‌کننده‌ها، پیام‌های خصوصی یا تحلیل مخاطب.**
- **کار روی حساب دیگران** یا چند حساب به‌صورت انبوه.
- **API رسمی و حالت دستی:** هر دو در تصمیم ۱ نوامبر کنار گذاشته شدند. Xomoni فقط حالت خودکار با یک‌پنجم محدودیت‌ها دارد.
- **هر روشی برای پنهان کردن خودکار بودن از X:** هرگز.

## محدودیت‌ها و ریسک‌ها

- **ریسک صفر نیست.** قوانین X خودکارسازی غیر API را ممنوع می‌کند. Xomoni ریسک را پایین نگه می‌دارد، ولی تصمیم نهایی با X است. این در صفحه‌ی [ریسک‌ها](https://xomoni.com/risks) و رضایت‌نامه‌ی افزونه گفته شده.
- **داشبورد باید باز باشد.** موتور کارها در خود داشبورد اجرا می‌شود.
- **ساختن آرشیو با X است** و ۱ تا ۳ روز طول می‌کشد. ممکن است X دوباره رمز بخواهد.
- **رابط افزونه انگلیسی است.**
- **نصب فعلاً از GitHub است.** هنوز در Chrome Web Store نیست، پس به‌روزرسانی خودکار ندارد ([#43](https://github.com/pirdehi/xomoni/issues/43)).
- **پلن رایگان Supabase:** اگر سایت چند روز بی‌استفاده بماند، پایگاه داده‌ی سایت متوقف می‌شود. این برای خود افزونه اثری ندارد.
